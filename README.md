# 🤖 AI ChatBot

A full-stack AI-powered chatbot built using React, Node.js, Express, and OpenRouter API.

## 🚀 Features

* Real-time AI conversations
* Modern responsive UI
* Markdown response rendering
* Secure API key management using `.env`
* React frontend with Vite
* Express.js backend
* OpenRouter AI integration

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* Axios
* React Markdown

### Backend

* Node.js
* Express.js
* OpenRouter API

## 📦 Installation

### Clone Repository

```bash
git clone https://github.com/ambasthashreya08-commits/Ai-Chatbot.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
node server.js
```
